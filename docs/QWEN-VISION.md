# 网页 Qwen 识别

网页上传识别默认使用 qwen3-vl-plus，由 FastAPI 调用。密钥只在后端读取项目根目录 百炼.env 或 .env，环境变量优先。

配置：DASHSCOPE_API_KEY（或 LLM_API_KEY），可选 QWEN_VISION_MODEL、QWEN_VISION_BASE_URL。默认地址为项目负责人提供的北京工作空间地址。不要提交或打包任何 *.env 文件。

本机运行：在项目根目录 python run_backend.py。修改后先在现有后端窗口 Ctrl+C，再运行上述命令；前端刷新即可。Compose 使用 docker compose up -d --build，要求支持可选 env_file 的较新 Compose。镜像新增 OpenCV headless 依赖；不再依赖 YOLO 或 PyTorch 执行网页识别。Compose 环境本次未实际运行验证。

图片发送原始文件；视频逐帧解码，按用户间隔和12帧上限选择采样，PNG无损编码发送，不缩小像素。云服务可能缩放。图片最多4000万像素、文件100MB，云服务自身限制可能更小，此时返回失败而不偷偷压缩。视频最长120秒、最多12次调用，每次90秒超时，不自动重试。使用会消耗百炼额度。

不产生检测框：预览为原始画面。结果包含自行车、电动两轮车、类型不确定、人员及两轮合计。未知类型包含在合计中；容载率可超过100%。普通视频逐采样帧统计，不求和，不是跟踪去重流量。上传计数为估算，非实时状态；原历史YOLO任务不改写。健康检查仅检查配置和依赖，不证明云端可达。

多角度识别从标注工作台提交：先关联地图停车区和采集批次、保存可停范围，再选择1～6个原图或视频帧。Qwen一次联合估算去重总数、区内数量、周边违停和位置不明数量；分项之和必须等于总数，违停不重复相加。原始图像合计最多24MB。地图区容量由后端读取，修改容量后概览与推荐会重算比例。完整操作见 [停车、公交与多角度说明](PARKING-TRANSIT-MULTIVIEW.md)。
