给标注同学：直接在负责人的电脑上操作

你负责什么

先不在你的电脑安装软件。今天在负责人电脑上打开调试网页，完成两种标注，负责人负责启动和备份。

工作在哪里操作画什么
照片、视频画面标注调试页 → 人车识别 → 可停车范围标注画面里允许停车的地面范围
校园地图停车区调试页右上角 → 地图停车区标注地图上的真实停车区域边界

两种标注不是同一个坐标系，不能互相复制。照片标注是画面位置，地图标注是经纬度位置。

打开网页

- 应用页：http://127.0.0.1:5174/ 。这是导航展示，不在这里改数据。

- 调试页：http://127.0.0.1:5174/debug 。你的工作都在这里。

- 两个网页可以同时打开，共用已启动的前后端，不必再开一套服务。

打不开时请负责人启动服务，不要自己删除文件、重装软件或关闭终端。后端和前端两个终端窗口需要保持运行。

先整理今天拍的素材

按位置分文件夹，例如“修远楼西侧”“鸿翔园1号公寓东侧”。文件名建议含地点、日期、镜头编号，例如 修远西侧_20261016_机位01_001.jpg。原照片、原视频另存一份，标注工具不会替你管理唯一原件。

优先拍清地面边界。视频尽量固定机位、避免来回晃动。一个视频换了机位，就按新的画面重新标注。推荐 JPG/PNG 照片、H.264 编码的 MP4 视频；某些手机 MOV/HEVC 在浏览器不能播放，需要负责人转码，不要反复重复上传。

单个文件最多100MB，视频最多30分钟。长视频请先截成片段。这里不会把照片发给 Qwen；不要误点旁边的“开始识别”。

照片标注：只画绿色区域

1. 点击“人车识别”，再点“可停车范围标注 · 批量素材”。会打开全屏工作台。

2. 点击“批量添加照片 / 视频”，可以一次选多张。等待上传完成。

3. 在“素材库”选择要标注的照片，确认位置和文件名。

4. 在照片上沿着允许停车的边界依次单击，至少3个点。四边形通常点4次；曲折边界可多点几次。

5. 不要最后再点一次起点，系统会自动闭合。点错用“撤销顶点”，整片画错用“清空草稿”。

6. 点击“完成区域”。有几块不相连的可停地面，就分别画几块。

7. 填写必要备注，例如“白线内”“拍摄机位01”。备注应在完成区域前填；也可选中已完成区域后修改。

8. 点击“确认本帧并保存”，看到“已保存到数据库 · 版本…”才算交付成功。

9. 点击“重新加载已保存版本”，确认绿色区域还在，再换下一张。

规则：确认后的画面，所有绿色区域的并集是可停车范围，其他地方都是不可停车范围。不需要再画红色禁停区，也不用逐辆画车。红色淡遮罩是系统显示的区域外范围，不是自动识别出的违停车辆。

如果整张画面确实没有任何可停车区，不画区域，直接“确认本帧并保存”，确认提示后即可。没有审核过的素材仍为“未知”，不会自动当成全图禁停。

不要因为某个位置已经停了很多车，就认定那里允许停车。通道、消防口、门口、绿地等边界请按现场规则与负责人确认。遮挡太重、看不清的先记在交接记录里，不凭空补边界。

视频标注

1. 从素材库打开视频，播放到要标注的位置，点击“暂停”。

2. 使用画面下方时间滑杆定位；记下当前秒数。

3. 按照片的办法画区域，点击“确认本帧并保存”。

4. 移到另一个要审核的时刻，再画、再保存。左侧已完成标注会显示对应秒数，点击可返回该时刻。

当前版本保存的是单帧标注，不会自动跟踪或把区域套用整段视频。即使固定机位，也不要误认为标注一帧就审核了所有帧。播放或拖动时未完成的顶点会清空，请先完成区域再换帧。

修改、导出

点击左侧已完成标注，可修改备注；边界画错可以删除该区域后重画，再保存。离开时提示“未保存修改”，请取消返回并保存。

每做完一批素材，点击“导出 JSON”，放到当天的备份文件夹。JSON 是标注，不包含原照片和视频。换电脑时必须同时交付素材和数据库备份，不能只带 JSON 就认为全部数据都在。

地图停车区标注

1. 返回调试页，点右上角“地图停车区标注”。

2. 缩放地图，找到真实位置。先对照建筑、道路、采集照片确认，避免圈错楼。

3. 填“新区域名称”，使用“建筑名＋方位”，例如“鸿翔园1号公寓东侧”。容量填负责人确认的参考值，不能把照片里当前车辆数当成总容量。

4. 点击“开始画边界”，沿真实停车范围逐点单击地图，至少3点。

5. 点“完成区域”，再点“保存到数据库”。看到保存成功后，点击重新加载核对。

6. 每批结束点“导出 GeoJSON 备份”。

不需要给每辆车画地图区域。每片实际停车场地画一个区域，排除楼体、花坛和人行通道。已有区域可以修改名称、容量；边界错误需删除重画。如果提示“仍关联道路入口”，请负责人先解除入口关联，不要乱改区域ID。

部分早期导入的边界有交叉或重复点，工具会保留原状并提示核对。优先让负责人确认这些区域，再重画。新区域如果边界交叉，保存会拒绝；按照边缘顺时针或逆时针依次点击即可。

每天交接时检查

- 每张照片、每个审核帧已点保存，并重新加载确认。

- 列出已完成文件、视频秒数、位置不确定或边界不清的素材。

- 地图区域名称、方位和容量已与负责人核对。

- 导出的 JSON、GeoJSON 放到当天文件夹。

- 请负责人执行完整数据备份；不要把照片、数据库和百炼密钥上传公开 GitHub。
