# 给标注同学：直接在负责人的电脑上操作

今天先用负责人的电脑，不用安装环境。应用页是 http://127.0.0.1:5174/ ，所有标注工具在 http://127.0.0.1:5174/debug 。负责人负责启动和数据备份。

## 你负责的三项工作

- 照片、视频：只画画面里允许停车的地面范围，并关联地图停车区。
- 地图：画真实停车场地的经纬度边界，填写名称和容量。
- 公交：根据你们掌握的资料绘制线路和停站点。

画面区域和地图区域坐标不同，通过停车区ID关联，不复制两者坐标。

## 先在地图上建立停车区

1. 打开调试页，点击右上角“地图停车区标注”。
2. 找到实地位置，填写名称，例如“修远楼西侧”。容量填写该场地的总容量，不要用当前照片车辆数代替。
3. 点击“开始画边界”，沿边缘按顺序点击至少3个顶点。
4. 点击“完成区域”，再点“保存到数据库”。
5. 每片停车场地画一个区域，排除楼体、花坛和通道；有问题的边界可以删除重画。

删除区域前，需要先解除道路入口及照片素材对它的关联。改名称不会改变区域ID。

## 照片标注与地图关联

1. 调试页 → 人车识别 → 可停车范围标注。
2. 批量添加照片或视频，在素材库中选择要处理的文件。
3. 在“本画面归属”选择刚才建立的地图停车区。
4. 填写“视角名称”，例如东侧俯拍；填写“同一时刻采集批次”，例如“修远西侧-10月16日14点”。同区同一时段的不同视角用同一个批次，跨时段另建批次。
5. 在画面上依次点击可停车范围边界，点“完成区域”。可以画多个区域，它们合起来就是可停车范围。
6. 点击“确认本帧并保存”。

绿色范围以外为不可停车。整幅画面的可停范围及周边违停归属所选停车区，所以素材应只覆盖这一停车区及它负责的周边。不要在一个素材里混入多个停车区。你不需要逐辆画违停框。

每个文件最多100MB；标注工作台视频最长30分钟。原始素材保留在后端。边界画错可撤销顶点，或删除已完成区域再重画；离开前保存。

## 视频怎么做

先暂停或拖动进度条，选定要处理的一帧，再画范围并保存。每一帧独立标注，区域不会自动跟着移动镜头走，也不会套用整段视频。

播放或换帧会清空未完成的顶点，所以先完成当前区域再切帧。

## 多角度联合识别

1. 为同一区域、同一时段的各个角度完成关联与标注并保存。
2. 点击“读取同区同批次已保存视角”。
3. 勾选1～6张照片或视频帧，点击“联合识别所选视角”。
4. 等待显示总数、容载率、区内数量、违停数量及位置不明数量。

本步骤调用百炼API并产生费用；最多6个原尺寸画面、合计24MB，不会自动缩图。各视角由Qwen联合估算，不直接相加。

违停已经包含在总数中。例如区内100、违停20，总数120；地图容量100时容载率为120%。不要再把20加到120上。新批次替换旧批次，不累加不同时间的车辆数。

关联停车区后，总容量自动来自地图区域，不能在识别面板随意覆盖。未关联的普通单文件测试仍可自行填写参考容量。

## 公交线路和站点

1. 调试页左侧点击“公交”，进入公交工作台。
2. “新增线路”，填写线路名，按行车方向沿道路点击地图绘制折线；结束后点“结束绘制”。
3. 填写新站名，点“在地图添加站点”，再点击地图放置。
4. 在线路下勾选停站点，使用上下箭头调整行车顺序。往返线路可以分别绘制。
5. 点击“保存全部”。应用页打开“公交线路”开关就能看到。

负责人可以为线路添加车辆，填写总容量和摄像头ID；保存后可输入测试车内人数。摄像头识别程序以后通过人数上报接口更新数据，不用你配置摄像头程序。

## 保存和交接

每批完成后导出标注JSON、地图GeoJSON、公交JSON，放到当天文件夹。导出JSON不包含原照片和视频，换电脑时由负责人一起迁移完整备份。

把以下记录发给负责人：

```text
日期 / 标注人：
完成的照片、视频与秒数：
对应地图停车区：
采集批次及视角：
新增或修改的地图停车区、容量：
公交线路与站点：
导出文件保存位置：
```
