# 用户停车区导入记录

- 原件：`parking.upload.original.geojson`；当前使用：`parking.imported.geojson`。
- 7 个区域保留原 ID、名称、坐标及容量数值（6 个 100、1 个 200，共 800）。容量来源为用户字段 `capility`，未独立核验。
- 2 个无名称、无 ID 的单点 LineString 不作为停车区导入，原件保留。
- 7 条边界按原顺序转为 Polygon，去掉连续重复坐标，末尾连接回起点。未改变原有点的坐标，未推测新的地理位置。原线条部分接近但未严格闭合，补闭合边仅用于区域展示，仍需人工检查边界。
- 地图按全体边界自动居中和缩放，范围中心为北纬 34.372000、东经 108.897283。不是实测建筑物中心或面积质心。
- 顶层 `is_example=false` 表示用户导入数据，并不表示系统已经核验真实性。全部停车占用状态依旧由模拟接口生成。
